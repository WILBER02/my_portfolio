Featured Project

Software Engineering Portfolio

Featured PHP MySQL JavaScript Bootstrap

Switor Fashion — E-commerce Website

A complete online fashion store built to move a local retail business online.

Problem

The business sold fashion items offline with no catalog, no inventory visibility, and manual order handling — limiting reach and creating errors.

Solution

A full-stack storefront: responsive UI, user registration/login with secure authentication, shopping cart, product catalog, and a MySQL-backed PHP backend.

Challenges

Keeping cart state consistent across pages, defending against SQL injection & XSS, and making tables and images truly responsive on mobile.

Lessons Learned

Design the database schema before writing code; sanitize every input; modular code pays off; and testing on real devices is non-negotiable.
